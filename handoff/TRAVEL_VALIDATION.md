## 실제 데스크톱 브라우저

Codex 앱 내 Chromium 브라우저에서 별도 정적 서버 `127.0.0.1:4176`으로 처음 설치하여 “오프라인 준비 완료”를 확인했습니다. 해당 서버를 완전히 종료한 뒤 페이지를 새로고침했고, 메인 지도·학교 코너(6,568개 path)·2층 지도(6,466개 path) 전환 및 “넥슨” 검색 결과를 확인했습니다. 지도 안내의 준비 완료 표시도 유지됐습니다.

검증 중의 다운로드 단계 진단 메시지는 최종 소스에서 제거했습니다. 개발 서버 5173은 이 테스트와 분리해 유지했습니다.

이 결과는 실제 iPhone Safari, 홈 화면 앱 또는 iOS 비행기 모드 검증이 아닙니다. 사용자 iPhone의 개발 주소 접속은 앞서 확인됐으나 여행용 홈 화면 설치·목록 이전·비행기 모드 실행은 `TRAVEL_START_HERE.md`의 절차로 확인해야 합니다.
