# 2026-09-12 — 인디관·상세 정보·하단 메뉴

## 범위

- 메인 160 + 학교 67 + 9–11홀 151 + 9홀 인디 36 + SELECTED INDIE 80 79 + 비즈니스 확대도 64 = 부스 557개.
- SELECTED INDIE 80은 공식 구역 이름이다. 제공된 PDF에서 실제 번호를 확인한 79개만 연결했다. E-01·E-04를 임의 추가하지 않았다.
- 9–11홀의 공식 화장실 아이콘 20개를 추가해 총 68개 편의시설이다. 기존 도면 3개와 부스 좌표·저장 키를 유지했다.
- 추가 도면은 공식 PDF 2쪽의 벡터 원본이다. 추측 부스 위치나 생성형 이미지가 없다.
- 전시관·시설 메뉴는 휴대전화 화면 하단, 관심 목록 아래다. 전시관 메뉴는 좌우로 넘길 수 있다.
- 파랑 게임패드: 시연 확인. 주황 티켓: 일부 또는 전체 작품의 정리권·예약 조건 확인. 보라 쇼핑백: 판매 확인. 부스 오른쪽 위 모서리에 배치한다.
- 상세 정보는 전시·시연, 정리권, 굿즈, 판매 정보, 관련 판매 부스 이동, 확인 날짜, 공식 출처 순서다.
- 개별 조사 12개 + 공식 PDF의 상품판매 구역 보완 22개 = 34개 정보 레코드. 나머지는 미확인이다. 정리권 잔량·재고를 실시간으로 확인하는 기능은 없다.

## 검증

`npm test`의 모의 DOM, 로컬 서버, 서비스 워커 검증을 통과했다. 7개 도면 전환, E2 번호 검색, 신규 부스 길게 누르기·관심 복원, 관련 판매 부스 이동, 필터·SVG 아이콘, 홈 화면 높이와 키보드 축소 처리를 포함한다.

데스크톱 브라우저의 화면 크기를 변경해 하단 메뉴와 모서리 아이콘을 확인했다. 실제 iPhone/iOS 검증은 아니다. iPhone의 safe area, 홈 화면 시작 높이, 키보드, 비행기 모드는 실기기 확인이 필요하다.

## 데이터 갱신

일반 코드 수정에는 지도 재추출이 필요 없다. PDF를 갱신할 때만 좌표 추출 후 원본과 대조한다. 상세 자료 변경 후 `node scripts/build-booth-details.cjs`를 실행한다. 배포 시 `dist/sw.js` VERSION과 HTML tgs-travel-version을 함께 올린다.

데스크톱 정적 서버를 종료한 뒤 새로고침해 7개 도면과 인디 E2 검색·상세 정보가 캐시에서 열리는 것도 확인했다. 세로 430×932, 가로 932×430, PC 1440×900에서 문서 스크롤이 없고 메뉴와 상세 패널이 화면에 들어왔다. 원본 227개 부스와 기존 SVG 3개의 내용이 유지된 것을 비교했다.
