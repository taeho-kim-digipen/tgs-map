# iPhone에서 작업 중인 지도 확인하기

## 처음 연결

1. Windows PC와 iPhone을 같은 Wi-Fi에 연결한다.
2. 프로젝트 폴더의 `START_PHONE_TEST.cmd`를 더블클릭한다. 터미널에서는 `npm run dev:phone`으로도 실행할 수 있다.
3. iPhone Safari에서 서버가 표시한 휴대전화 접속 주소를 연다.

2026-09-11 확인한 PC의 Wi-Fi 주소는 `192.168.0.4`다. 현재 접속 주소는 **http://192.168.0.4:5173/** 이다. PC에서는 http://127.0.0.1:5173/ 도 사용할 수 있다.

공유기 연결이나 PC 주소가 바뀌면 실행 창에 표시되는 새 주소를 사용한다. Safari에 책갈피로 저장해 두면 다시 열기 쉽다.

Codex가 이미 서버를 실행해 둔 상태라면 시작 파일을 다시 열 필요 없이 iPhone에서 접속하면 된다.

## 작업 중 확인

- PC의 개발 서버를 실행하고 iPhone에서 지도 페이지를 열어 둔다.
- `dist/`의 지도 앱 파일을 저장하면 열린 페이지가 자동으로 새로고침된다.
- 관심 부스는 같은 접속 주소의 Safari 저장 공간에 남는다. 새로고침으로 현재 지도 확대 위치나 열린 검색·상세 화면은 초기화될 수 있다.
- iPhone이 잠들었거나 Safari가 백그라운드에 있었다면 돌아온 뒤 최신 파일을 확인한다. 실제 iPhone에서의 복귀 동작은 첫 연결 때 함께 점검해야 한다.
- PC와 iPhone이 연결돼 있는 동안 계속 사용할 수 있다. 서버를 종료하거나 PC가 잠들면 접속이 끊긴다.

`npm run dev`는 기존처럼 PC 전용 주소에서 실행하면서 자동 새로고침을 제공한다. iPhone과 함께 확인할 때는 `npm run dev:phone`을 사용한다. 두 명령을 같은 5173 포트에서 동시에 실행하지 않는다.

## 접속되지 않을 때

1. 두 기기가 같은 Wi-Fi에 연결돼 있는지 확인한다. 게스트 Wi-Fi의 기기 간 통신 제한이 있으면 접속되지 않을 수 있다.
2. PC 서버가 실행 중이고, 실행 창에 나온 주소와 Safari 주소가 같은지 확인한다.
3. PC에서도 해당 내부 IP 주소가 열리는지 확인한다.
4. Windows 방화벽의 Node.js 허용 상태를 확인한다. 방화벽 전체를 끄지 않는다.

2026-09-11 이 PC에서는 Wi-Fi가 Public으로 분류돼 있었고, Node.js의 해당 프로필 수신 허용 규칙이 이미 있었다. 이번 작업에서 네트워크 분류나 방화벽 규칙을 변경하지 않았다.

## 확인 범위

이 연결은 현재 지도·검색·관심 부스·화면 회전의 실제 iPhone 확인을 위한 것이다. 2026-09-11 사용자가 iPhone Safari에서 위 주소의 지도가 열린다고 확인했다. 이는 접속 확인이며 iPhone의 모든 기능 검증을 뜻하지 않는다. PC의 접속 확인이나 브라우저 크기 변경을 iPhone 실기기 검증으로 보고하지 않는다.

카메라·GPS는 아직 미구현이다. 해당 기능을 개발할 때는 iPhone에서 신뢰할 수 있는 HTTPS 테스트 주소와 권한 처리를 준비한다. 웹·네이티브 방식의 최종 선택은 계속 미정이다.

## 구현 및 검증 기록 — 2026-09-11

- `scripts/serve.cjs`: 기존 PC 전용 실행 유지, `--lan` 접속과 개발 파일 변경 감지 추가. `--no-reload`는 개발 코드 없는 기존 정적 응답을 제공한다.
- `scripts/dev-client.js`: 약 1.5초 간격으로 변경을 확인하며, 파일 저장이 안정되면 브라우저를 새로고침한다. 화면 복귀·연결 복구·서버 재시작도 확인한다.
- 지도 우하단의 작은 상태 점을 탭하면 개발 서버 연결 상태를 펼치거나 접을 수 있다.
- `npm test`: 기존 지도 상호작용 테스트와 새 서버 통합 테스트 모두 통과했다. HTTP GET/HEAD, 파일 추가·수정·삭제, 경로 및 junction 탈출 차단, HTML 원본 보존, 정적 모드, 재연결·백그라운드 복귀 로직을 검증했다. 클라이언트 재연결 테스트는 모의 DOM이다.
- 실제 PC 브라우저에서 임시 파일 저장 후 HTML의 개발 버전이 `:0`에서 `:1`로 자동 갱신되는 것을 확인했다. 검증용 임시 파일은 내용 확인 후 제거했다.
- PC의 LAN 주소에서 HTTP 200 응답 확인. 사용자가 iPhone에서 지도 열림을 별도로 확인했다.
- 기존 지도·부스 좌표·저장 키는 변경하지 않았다. 외부 패키지를 설치하거나 인터넷에 공개 배포하지 않았다.
