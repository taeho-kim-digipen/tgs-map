# 실행

Node.js 20 이상 설치 후 이 폴더에서 `npm run dev`를 실행하고 `http://localhost:5173`을 엽니다. `npm install`이나 빌드는 필요 없습니다. `dist/`가 실제 웹사이트 파일입니다. 아이폰 위치·방향 기능은 HTTPS 배포 주소에서 사용하세요.

# 게임·굿즈 정보 추가

`dist/data.json`에서 항목을 수정하거나 아래 형식으로 추가한 후 저장하고 새로고침하세요. JSON 항목 사이는 쉼표로 구분합니다.

```json
{
  "booth": "07-C04",
  "game": "게임 이름",
  "goods": "굿즈 이름",
  "image": "./images/goods.jpg",
  "condition": "시연 후 수령"
}
```

`booth`는 기존 지도 부스 번호 또는 정확한 부스명입니다. 같은 부스에 항목을 여러 개 추가할 수 있습니다. `game`은 줄바꿈으로 여러 게임을 적을 수 있습니다. 이미지 파일은 `dist/images/`에 넣거나 HTTPS 이미지 주소를 쓰세요. 이미지가 없으면 빈 문자열을 유지하세요. 기존 항목의 출처·정리권·시연·판매 필드는 그대로 두면 됩니다. 게임과 굿즈는 검색 및 부스 상세에 자동 반영됩니다. 새 부스의 지도 위치를 추가하려면 `map-data.json`에 공식 좌표가 필요합니다.

로컬 `npm run dev`에서는 저장한 수정이 반영됩니다. 배포본을 갱신할 때는 `dist/sw.js`의 VERSION과 `dist/index.html`의 tgs-travel-version을 같은 새 값으로 바꾼 뒤 dist 전체를 배포하세요. 추가 이미지는 온라인에서 표시되며 오프라인에도 필요하면 sw.js의 FILES에 경로를 넣으세요.
